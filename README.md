# EventPulse — Pune Event Impact Intelligence

**See the city before the event begins.**

EventPulse is an urban event intelligence platform designed to analyse and predict the potential impact of public events across Pune, India.

The platform brings together event data, impact analysis, geospatial visualisation, data warehousing and machine learning concepts to help understand how large gatherings can influence urban mobility and city infrastructure.

🌐 **Live Demo:** https://event-q-app.vercel.app/  
💻 **GitHub Repository:** https://github.com/Vidmah/EventQ_app

---

## Project Overview

Public events can significantly affect traffic flow, crowd density, parking availability and urban mobility.

EventPulse provides an interactive workspace to explore these effects through event analytics, visual dashboards and predictive analysis.

The project focuses on five key impact dimensions:

- Traffic congestion
- Crowd density
- Parking stress
- Public transit impact
- Noise levels

Its goal is to make complex event-impact information easier to explore and interpret.

##  Key Features

### 1. Executive Dashboard
- Overview of registered events.
- High-risk event indicators.
- Traffic and parking impact metrics.
- Visual summaries and analytical charts.

### 2. Events Directory
- Explore events across Pune.
- View event information and locations.
- Organise events by relevant attributes.

### 3. Interactive Pune Map
- Geographic visualisation of event locations.
- Explore event distribution across Pune zones.
- Understand spatial patterns.

### 4. Event Impact Prediction
- Simulate potential event conditions.
- Analyse traffic, crowd and parking pressure.
- Explore predicted impact categories.

### 5. Data Warehousing
- Star schema data warehouse.
- ETL pipeline concepts.
- OLAP-based analytical exploration.

### 6. Data Mining and Machine Learning
The project explores data mining and machine learning techniques, including:

- Apriori association rule mining.
- K-Means clustering.
- Classification using J48.
- Model evaluation and analytical visualisation.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Vidmah/EventQ_app.git
```

2. Navigate to the application directory:

```bash
cd EventQ_app/eventq-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

##  Project Scope

EventPulse is an academic project exploring how data analytics and machine learning concepts can be applied to urban event-impact analysis.

The displayed metrics and predictions should be interpreted according to the underlying project dataset and implementation. They should not be treated as verified live municipal traffic measurements or official emergency forecasts.
